# PyT — Python, from the basics to the standard library

Learning log for Python. I work through exercises topic by topic and commit each solution, so the history shows the progression (187 commits between February and July 2025).

## Contents

| Folder | Topic |
|---|---|

| `data structures/` | Lists and list comprehensions, dictionaries, sets, queues |
| `input_output/` | Reading and writing files, `print`/`input`, formats (exercises 1–50) |
| `modules/` | Modules and packages: imports, `__init__.py`, sub-packages, project layout (22 exercises) |

`objectives.md` is the study plan I follow for the standard library (`sys`, `os`, `pathlib`, `collections`, `itertools`, `functools`, …).

## Running an exercise

Each exercise is standalone. Run it from its own folder so relative paths to data files work:

```bash
cd "input_output/1-15/3"
python Reading_a_Single_File3.py
```

Python 3.10 or later.
